# Changelog

## [0.1.0] - 2026-10-18

### Added

- Change existing Steam lobby visibility between **Friends** and **Public** during a session.
- Host-only toggle integrated into the Session window beneath its title.
- Pixel-art button with stepped corners and hover styling.
- Expanded Session window and player-list viewport for all four player slots.
- Steam lobby ownership checks and preservation of the game's join-lock state.

### Notes

- Visibility is controlled from **Pause → Session**; there is no keyboard shortcut.
- Tested with **Stonewards 0.2.3**.
